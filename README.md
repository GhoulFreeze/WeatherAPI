# WeatherAPI - Консольное приложение для получения данных о погоде

## 📋 Описание проекта

Данный проект представляет собой консольное приложение на языке Python, реализующее клиент для взаимодействия с погодным сервисом **OpenWeatherMap** через **REST API**. Программа принимает от пользователя название города, отправляет HTTP-запрос к внешнему серверу, обрабатывает полученный JSON-ответ и выводит структурированную информацию о текущих погодных условиях.

### Основной функционал

- Получение текущей температуры воздуха (фактической и ощущаемой)
- Определение уровня влажности
- Вывод скорости ветра
- Отображение текстового описания погодных условий (облачность, осадки и т.д.)
- Обработка ошибок при вводе данных и сетевых запросах
- Интернационализация: вывод описания погоды на русском языке

## 🛠 Технический стек

| Компонент | Описание |

## 📦 Установка и настройка

### 1. Клонирование репозитория

```bash
git clone https://github.com/GodOfCCult/WeatherAPI.git
cd WeatherAPI

2. Установка зависимостей
Для работы программы требуется библиотека requests. Установка выполняется командой:

bash
pip install -r requirements.txt
Содержимое файла requirements.txt:

text
requests>=2.28.0
3. Получение API-ключа
Для доступа к данным OpenWeatherMap необходимо:

Зарегистрироваться на сайте OpenWeatherMap

Получить бесплатный API-ключ в личном кабинете

Вставить полученный ключ в переменную API_KEY в файле Weather.py

python
API_KEY = "ваш_api_ключ"  # Заменить на действительный ключ
4. Настройка параметров запроса
В программе используются следующие параметры:

Параметр	Значение	Описание
q	Пользовательский ввод	Название города (на английском языке)
appid	API-ключ	Идентификатор для доступа к API
units	metric	Метрическая система (градусы Цельсия, м/с)
lang	ru	Язык текстового описания погоды
🖥 Использование
Запуск программы
bash
python Weather.py
